Website single page bertema kedai kopi menggunakan React, React Bootstrap, dan Bootstrap.

## Fitur
- Carousel / sliding banner tiga slide.
- Navbar responsif dengan hamburger menu.
- Penanda menu aktif pada Navbar.
- Navigasi satu halaman: Beranda, Tentang, Menu, Kontak.
- Kartu menu kopi beserta gambar, deskripsi, dan harga.
- Responsive design untuk desktop, tablet, dan smartphone.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `tugas-5-praktikum-kopi-senja` di VS Code.
3. Pastikan file `package.json` terlihat di panel Explorer.
4. Buka Terminal > New Terminal.
5. Jalankan `npm install`.
6. Jalankan `npm run dev`.
7. Buka alamat yang ditampilkan Vite, biasanya http://localhost:5173.

Gambar dan Google Fonts diambil dari internet sehingga memerlukan koneksi internet.
